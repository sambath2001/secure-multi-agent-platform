# Security Policy (v4, effective 2026-01-01)

1. Passwords must be rotated every 90 days.
2. Multi-factor authentication is required for all internal tools.
3. Security incidents must be reported within 24 hours.
4. SEV1 pages must be acknowledged within 10 minutes.
5. Telemetry data is retained for 400 days, then deleted.
6. Access reviews are performed every quarter by the Security team.
7. Production secrets must never be copied into notes, tickets, or chat.
